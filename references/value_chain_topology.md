## 1. AI 硬件 7 大物理层级的供需传输拓扑 (Physical Pipeline)

物理层面上，从最上游原材料与制造流向终端云厂商的绝对输送路径如下：

```text
【一层：芯片制造与先进封测】台积电(CoWoS/N3P) ──▶ 旺矽/精测/颖崴(HBM4探针卡/Socket) ──▶ 健策(均热片/ILM)
                                   │
                                   ▼ (生成 GPU/ASIC 核心算力单元)
【二层：物理连接与信号重构】Astera Labs(ALAB PCIe6.0) / Credo / 安费诺&神宇(背板铜线束)
                                   │
                                   ▼ (信号补强与高速互联)
【三层：高频基材与高阶板材】台光电/台燿(M8/M9 CCL) ──▶ 胜宏科技/沪电/工业富联(50层+ OAM/UBB/Switch板)
                                   │
                                   ▼ (装配板卡与交换网络)
【四层：光通信&电源散热】中际旭创/新易盛/天孚(1.6T光模块&光引擎) ──▶ 麦格米特(800V电源) ──▶ 英维克(CDU液冷)
                                   │
                                   ▼ (完成物理级机柜组装)
【五层：机柜总装 ODM】广达 / 鸿海 / 工业富联 (NVL72 / NVL144 机柜级垂直集成)
                                   │
                                   ▼ (Capex 结算与部署)
【六层：终端云厂商结算】Microsoft / Google / Meta / Amazon / Oracle (四大 CSP & 算力云)
```

## 2. 核心标的分析框架与主营纯度审计方法 (Product Pureness Audit)

在分析具体标的业绩弹性时，必须按以下框架审计其“AI 主营纯度”：

### A. 光通信与光连接 (High Pureness Sector)
- **核心标的**：中际旭创 (300308)、新易盛 (300502)、天孚通信 (300394)、太辰光 (300570).
- **主营纯度审计要点**：
  - 光通信模块业务占总营收比例（通常 > 90%）。
  - 重点检索：最新季度 **1.6T / 800G 高端光模块** 在其总出货中的结构占比（高端占比越高，单价 ASP 与毛利率弹性越大）。

### B. 高阶 PCB、HDI 板与高速线缆
- **核心标的**：胜宏科技 (300476)、沪电股份 (002463)、工业富联 (601138)、神宇股份 (300563)、沃尔核材 (002130).
- **主营纯度审计要点**：
  - 胜宏科技/沪电：重点检索其 **高阶 HDI / 50层+ 算力卡板** 收入增幅，排查消费电子/传统 PCB 的干扰。
  - 神宇股份/沃尔核材：检索其 **NVL72/144 机柜内高速细微同轴铜线** 的交付量与单柜价值量占比。

### C. 芯片解热、机柜高压电源与液冷
- **核心标的**：健策 (3653.TW)、麦格米特 (002851)、英维克 (002837).
- **主营纯度审计要点**：
  - 健策 (3653)：均热片 (Heat Spreader) 收入占比及在 NVDA B300/R100 单芯片 1000W+ 上的份额。
  - 麦格米特 (002851)：重点检索其 **800V DC 专有 Power Shelf** 模块在 NVDA 机柜供应链中的营收边际突破。
  - 英维克 (002837)：算力液冷业务（CDU、冷板、快换接头）占总营收比重。

## 3. 动态防偏差与自进化机制

1. **联网强制审计原则**：静态拓扑仅用于定位物理环节，一切主营占比与份额数据**以当前联网检索出的最新财报数据为准**。
2. **主动更新提醒**：若检索到某公司 AI 业务比重跨越式提升（如突破 50%）或切入新架构供应，在分析末尾触发知识库更新提示。
