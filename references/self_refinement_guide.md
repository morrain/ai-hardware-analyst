# Skill 自我完善与知识演进指南 (Self-Refinement Protocol)

为了保持本 Skill 对全球硬科技产业链最新代际演进（如 Blackwell → Rubin、HBM3e → HBM4、1.6T → CPO 硅光）的敏锐度和准确性，制定本标准化自我完善机制。

---

## 1. 增量标的与技术路线捕获机制 (Knowledge Capture Protocol)

在分析过程中触发网络检索时，模型若发现以下情景，必须触发“增量捕获”提示：

1. **新供应商入链**：如某新厂商（美/台/A）通过 NVDA NVL72/B300 验证或入选 4大 CSP 自研芯片供应链。
2. **技术路线拐点到来**：
   - 如光模块 1.6T 量产拐点爆发或 CPO 在 Tier-1 厂商机柜中正式替代传统可插拔模块。
   - HBM4 开始采用 2048-bit 接口，先进封测从 CoWoS-L 进一步转向逻辑 Base Die / 3D IC 整合。
3. **交互触发提示**：
   ```markdown
   > [!TIP]
   > **知识库演进提示**：检索到最新公开信息显示 [公司/技术节点] 发生了 [具体变化]。建议更新 `references/` 对应的映射文件。
   ```

---

## 2. 高频数据校验与周期刷新规程 (Data Refresh Schedule)

模型在回答高频交货数据时，遵循以下刷新节点：

- **每月 1 日 - 10 日**：台股月度营收公布期。优先检索广达、鸿海、纬创、信骅、台光电等上一月营收，校验上季度指引落地情况。
- **每季度末后 1 个月**：美股 CSP 与 NVDA/TSMC 财报集中季。更新下季度 Capex 与 CoWoS 产能指引。

---

## 3. 范例沉淀规范 (Case Study Harvest)

当某次投研对话满足以下条件时，可提炼归档入 `examples/` 目录：
1. 问题具有代表性（涵盖多公司比价、三地市场映射、时间错配或新机柜解构）。
2. 分析过程严密，准确应用了动态 Markdown 表格、数据铁律与截止时间标注。
3. 用户给予积极反馈或明确肯定。

沉淀格式详见 [deep_report.md](../templates/deep_report.md)。
