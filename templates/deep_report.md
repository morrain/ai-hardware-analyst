# 深度分析报告结构与 Markdown 表格样式 (Deep Report Template)

适用于用户要求“梳理逻辑”、“写分析报告”或提问涉及复杂的跨市场产业链推演时。根据用户诉求智能选择以下分支格式：

---

## 分支 1：通用全球产业链深度报告格式 (Default)

```markdown

> **数据检索截止时间**：截至 YYYY年MM月DD日

- [简明扼要的三点核心推演结论]

- [描述架构代际转换、物理层增量与壁垒变化]

- [判定当前处于“预期期”、“订单爆发期”还是“估值修正期”]
```
